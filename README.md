# Практическое задание 3Б — Справочник пользователей (REST API)

Автор: Наранбаатар Тунармаа, группа БПИ-23-РП-1

## Запуск
1. Распаковать архив.
2. Открыть `index.html` в браузере (сервер не нужен; нужен доступ в интернет).
3. Нажать «Загрузить пользователей».

Если сервер jsonplaceholder недоступен из-за сетевого сбоя, приложение показывает сохранённые демо-данные с пояснением. HTTP-ошибки (например 404) всегда выводятся как ошибка с кнопкой «Повторить».

Стек: HTML, CSS, чистый JavaScript (fetch, async/await, try/catch/finally), без фреймворков.

## Файлы
- `index.html` — разметка (кнопка, поле поиска, список пользователей, область публикаций, сообщения).
- `style.css` — оформление (отступы, цвета, карточки, кнопки, адаптивность).
- `app.js` — загрузка данных, поиск, публикации, обработка ошибок.

## Результаты проверок
| Проверка | Результат |
|---|---|
| Кнопка «Загрузить пользователей» | Выводятся 10 пользователей с именем, email и городом |
| Поиск «Leanne» (в т.ч. «LEANNE») | Остаётся 1 подходящая запись, регистр игнорируется, новый запрос не отправляется |
| Поиск неизвестного имени | Сообщение «Пользователи не найдены» |
| «Показать публикации» | Заголовки и тексты первых 3 публикаций выбранного пользователя |
| Замена `/users` на `/userz` (404) | Сообщение «Ошибка HTTP: 404 Not Found» и кнопка «Повторить» |
| Возврат корректного адреса, «Повторить» | Список загружается снова |
| «Загрузка...» и блокировка кнопки | Во время запроса кнопка отключена, после — включается (блок `finally`) |
